# OVERWORLD — GitHub Pages

Плоский пакет сайта: все файлы находятся в корне архива, вложенных папок нет.

## Загрузка
1. Распакуйте ZIP.
2. В GitHub откройте репозиторий → Add file → Upload files.
3. Выделите всё содержимое распакованной папки (Ctrl+A), дождитесь загрузки и нажмите Commit changes.
4. В Settings → Pages выберите ветку `main` и каталог `/ (root)`.

## Что изменено
- Наутилус использует предоставленную прозрачную 3D-иконку, встроенную в `icons.js`.
- Девять названий волков снова используют исходную ванильную иконку волка из EntitySprite, без экспериментальных кастомных картинок.
- Вкладка «Все» больше не перерисовывает Canvas бесконечно после завершения появления дерева; уменьшены частицы, свечение и разрешение Canvas для этого режима.
- Заголовок и счётчик вкладки перенесены внутрь верхней части поля дерева; само поле поднято выше.
- Интерфейс и текст слегка увеличены.

В корне должны находиться `index.html`, `catalog.js`, `icons.js`, `jszip.min.js` и остальные файлы архива.
