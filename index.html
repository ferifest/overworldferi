СПРАВКА

Где найти папку мира или ZIP?

Windows (обычный Minecraft): нажми Win + R, введи %appdata%\.minecraft\saves и нажми Enter. Открой папку нужного мира.

macOS: открой Finder → Перейти к папке и вставь ~/Library/Application Support/minecraft/saves.

Linux: открой ~/.minecraft/saves. Для некоторых сборок путь к папке Minecraft может отличаться.

Modrinth / другой лаунчер: открой настройки или папку нужного профиля, найди saves и выбери папку своего мира.

Что именно загружать?
  1. Выбирай папку конкретного мира — внутри обычно находятся level.dat, advancements и stats.
  2. Чтобы создать ZIP: в Windows нажми правой кнопкой по папке мира → Сжать в ZIP-файл (или «Отправить → Сжатая ZIP-папка»); в macOS выбери Сжать; в Linux — Сжать / Create Archive. Затем выбери получившийся архив через «или ZIP».
  3. Не выбирай только папку region или отдельные файлы чанков: в них нет прогресса достижений.

Файл обрабатывается локально в браузере и не отправляется на сервер сайта.
