# OVERWORLD

Веб-приложение для просмотра достижений Minecraft по сохранению мира.

## Загрузка на GitHub Pages

Этот архив подготовлен для GitHub Pages. Все файлы сайта находятся **в корне архива** — вложенных папок создавать или загружать не нужно.

1. Скачайте ZIP и распакуйте его на компьютере.
2. Откройте репозиторий GitHub.
3. Нажмите **Add file → Upload files**.
4. Откройте распакованную папку, выделите всё её содержимое (`Ctrl + A`) и перетащите файлы в окно GitHub.
5. Дождитесь окончания загрузки и нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните настройки.
8. После публикации откройте адрес GitHub Pages. Если показывается старая версия, обновите страницу сочетанием `Ctrl + F5`.

> Важно: загружайте именно распакованные файлы, а не сам ZIP. Не создавайте дополнительную папку вокруг файлов — `index.html` должен находиться в корне репозитория.

## Загрузка мира

1. Нажмите **Загрузить мир**.
2. Выберите ZIP-архив сохранения Minecraft либо папку мира, если браузер поддерживает выбор папки.
3. Для корректного чтения прогресса используйте полный мир с файлами `level.dat`, каталогом `advancements` и каталогом `stats`.
4. Дождитесь обработки сохранения. Не закрывайте вкладку во время импорта.

Если импорт не проходит, проверьте, что ZIP содержит саму папку мира и её содержимое, а не только ярлык или отдельные файлы. Не загружайте архив внутри другого архива.

## Состав

- `index.html` — интерфейс приложения.
- `catalog.js` — каталог достижений.
- `icons.js` и `sprites.js` — изображения и сопоставление иконок.
- `jszip.min.js` — локальная библиотека чтения ZIP.
- `BiomeSprite.png`, `EntitySprite.webp`, `InvSprite.webp` и отдельные PNG/WEBP — ресурсы Minecraft и дополнительные иконки.
- `.nojekyll` — отключает обработку GitHub Pages через Jekyll.

Все перечисленные ресурсы лежат рядом с `index.html`; внешняя папка `assets` не требуется.

## Последние изменения

- Для наутилуса используется отдельная иконка существа, а не яйцо призыва.
- Для девяти разновидностей волков возвращены исходные игровые текстуры.
- Оптимизирована анимация дерева достижений в режиме «Все»: уменьшена лишняя перерисовка Canvas и нагрузка от визуальных эффектов.
- Заголовок и счётчик выбранной категории перенесены в верхнюю часть области дерева.
- Немного увеличены элементы интерфейса и текст.

## Примечание

GitHub Pages размещает статический сайт и не запускает Node.js-сервер. Для текущей браузерной версии OVERWORLD достаточно GitHub Pages. Если проект будет переведён на серверную архитектуру Node.js, понадобится отдельный хостинг с поддержкой Node.js.
